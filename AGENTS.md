# Project Stack

- Frontend: React + TypeScript SPA built with Vite, React Router, and Tailwind CSS.
- Backend: Express REST API running on Cloudflare Workers.
- Persistence: Cloudflare D1; use Wrangler-generated Worker bindings.
- Load route pages lazily and keep API cache policies limited to public GET responses.
